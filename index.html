作品展示

🚀 AI 辅助 · 极简待办事项全栈应用

一个从零搭建的前后端分离待办事项应用。通过 AI 辅助生成核心代码，全程独立完成环境配置、调试排错与代码托管， 完整走通了"需求 → 开发 → 调试 → 部署"的项目闭环。

Node.js Express HTML / CSS / JS VS Code Git Gitcode AI 辅助编程
阶段一

环境与基础工具准备

⏱ 约 1 小时

搭建完整的开发环境，为后续编码打好地基。

  • 安装 VS Code 编辑器并配置中文语言包插件
  • 安装 Node.js LTS 长期支持版作为后端运行时
  • 安装 Git 版本控制工具，在 Gitcode 创建远程仓库 ai-todo-app
阶段二

利用 AI 生成核心代码

⏱ 约 1 ~ 2 小时

借助 AI 生成前后端代码，学习提示词工程与代码理解。

  • 使用 npm init -y 初始化项目，安装 Express 和 CORS 依赖
  • 通过精心设计的 Prompt 让 AI 生成后端 server.js：包含获取列表、添加任务、删除任务三个 RESTful 接口
  • 继续用 Prompt 生成前端 index.html：干净美观的现代界面，使用原生 fetch 调用后端 API
阶段三

本地跑通与报错调试

⏱ 约 30 分钟

运行项目并掌握"遇到问题 → 读懂报错 → AI 辅助修复"的调试方法论。

  • 终端执行 node server.js 启动后端服务
  • 浏览器打开前端页面，测试添加与删除功能
  • 利用 F12 开发者工具 Console 定位报错，复制给 AI 获取修复方案
阶段四

代码提交

⏱ 约 30 分钟

将代码推送到 Github 远程仓库，完成项目交付闭环。

  • 使用 git init → git add . → git commit → git push 推送代码到云端
